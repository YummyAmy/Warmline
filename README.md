# Warmline

**AI outreach in a human voice.** Write one real detail about someone you want
to reach, and get back an opening line that sounds like a person wrote it — not
a robot, not spam.

Most cold outreach dies on the first line. Warmline writes that line so it leads
with *them*, references something specific, and skips every tell-tale AI phrase
("I hope this email finds you well," "I came across your profile," and a long
banned-words list baked in).

Built as a single self-contained page. Free to use, no signup.

## What it does
- You give it a name, a company or newsletter, and one real detail you noticed.
- You pick a tone per prospect: Warm, Direct, Technical, or Executive.
- It returns a one- or two-sentence opener in a human voice.
- 15 free openers per browser. No signup.

## Who it's for
Freelancers pitching clients, job-seekers reaching hiring managers, and writers
doing collabs — anyone who sends cold messages without a sales team or a
$99/month tool.

## Why it exists
Built by a data analyst who got tired of beige, robotic AI outreach and wanted
one small tool that sounds like a human. Part of *data according to me*.

## Tech
A single self-contained HTML page. The AI call runs server-side so the API key
is never exposed to the browser.
